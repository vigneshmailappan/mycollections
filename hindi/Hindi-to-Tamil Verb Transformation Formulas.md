# ✅ Hindi-to-Tamil Verb Transformation Formulas

| **S.No** | **Formula** | **Meaning** | **Examples** |
|----------|-------------|-------------|--------------|
| **1** | Verb – naa + ஓ (oo) | Ask someone to do that action | Karnaa (செய்தல்) → karo (செய்)<br>Jaanaa (போதல்) → jao (போ)<br>Aanaa (வருதல்) → aao (வா)<br>**Exceptions:**<br>Dheynaa → dheydho (கொடு)<br>Laynaa → laylo (எடு)<br>Kehanaa → kaho (சொல்லு) |
| **2** | Verb – naa + யியே (yeeye) | Respectfully ask someone or multiple people (plural) to do that action | Jaanaa → jayeeye (போங்க)<br>Aanaa → aayeeye (வாங்க)<br>Barnaa → baryeeye (நிரப்புங்கள்)<br>**Exceptions:**<br>Dheynaa → dheejeeye (கொடுங்க)<br>Laynaa → leejeeye (எடுங்க)<br>Kehanaa → kaheeye (சொல்லுங்க)<br>Karnaa → keejeeye (செய்யுங்க)<br>Peenaa → peejeeye (குடிங்க) |
| **3** | Verb – naa + க்கே (kay) | To say “ட்டு” | Jaanaa → jaakay (போயிட்டு)<br>Aanaa → aakay (வந்துட்டு)<br>Bayjnaa → bayjkay (அனுப்பிட்டு) |
| **4** | Verb – naa + ஊNG (oong) | To say “ட்டுமா” or “ட்டும்” | Jaanaa → jaoong (போகட்டுமா / போகட்டும்)<br>Aanaa → aaoong (வரட்டுமா / வரட்டும்)<br>Barnaa → baroong (நிரப்பட்டுமா / நிரப்பட்டும்) |
| **5** | Verb – naa + aeng (hain) | To say “லாமா” (like போகலாமா) | Karnaa → kareng (செய்யலாமா)<br>Jaanaa → jaayeng (போகலாமா)<br>Aanaa → aaeng (வரலாமா)<br>**Exceptions:**<br>Dheynaa → dheydheyeng (கொடுக்கலாமா)<br>Laynaa → laylayeng (எடுக்கலாமா) |
| **6** | Verb – naa + த்தே சமய் | Means “அந்த சமயத்தில்” | Aanaa → aathe samay (வரும்போது)<br>Jaanaa → jathe samay (போகும்போது) |
| **7a** | Verb – naa + nay dho | Ask opponent to let you/others do the action (casual) | Jaanaa → jaa nay dho (போக விடு)<br>Bolnaa → bol nay dho (சொல்ல விடு)<br>Padnaa → pad nay dho (படிக்க விடு) |
| **7b** | Verb – naa + nay dheejeeye | Ask opponent to let you/others do the action (respectful) | Jaanaa → jaa nay dheejeeye (போக விடுங்க)<br>Bolnaa → bol nay dheejeeye (சொல்ல விடுங்க)<br>Padnaa → pad nay dheejeeye (படிக்க விடுங்க) |
| **8** | Verb + padaygaa | Means “ஆகணும்” (must/should) | Karnaa → karnaa padaygaa (செய்தாகணும்)<br>Jaanaa → jaanaa padaygaa (போயாகணும்)<br>Chalnaa → chalnaa padaygaa (போயாகணும்) |
| **9** | Verb + paduthaa hei | Means “வேண்டி இருக்கு” | Chalnaa → chalnaa padutha hei (போக வேண்டி இருக்கு)<br>Karnaa → karnaa padutha hei (செய்ய வேண்டி இருக்கு) |
| **10** | Verb – naa + Verb – naa + ke | அடுக்கு மொழி (repetitive action),இரட்டைக்கிளவி | Goomnaa → goom goom kay (சுத்திகிட்டு சுத்திகிட்டு)<br>Bytnaa → byt byt kay (உக்காந்து உக்காந்து)<br>Kaanaa → kaa kaa kay (சாப்பிட்டு சாப்பிட்டு) |
| **11** | Verb – naa + nay ko dhil/mann karthaa hei | “போல இருக்கு” – feel like doing that verb | Peenaa (குடித்தல்) → peenay ko dhil karthaa hei (குடிக்கணும் போல இருக்கு)<br>Jaanaa (போதல்) → janay ko dhil karthaa hei (போகணும் போல இருக்கு)<br>Kaanaa (சாப்பாடு / சாப்பிடுதல்) → janay ko dhil nahi karthaa hei (சாப்பிடணும் போல இல்ல) |
| **12** | Verb – naa + நே சே | “If” in English (like ‘வந்தால்’, ‘போனால்’) | Peenaa (குடித்தல்) → peenay say (குடித்தால்)<br>Jaanaa (போதல்) → janay say (போனால்)<br>Kaanaa (சாப்பாடு / சாப்பிடுதல்) → janay say (சாப்பிட்டால்) |
